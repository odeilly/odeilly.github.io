# Windows 11 でディスク クリーンアップを活用する方法

Windows を長く使っていると、知らないうちに不要なファイルがたまってディスク容量を圧迫していきます。
特に Windows のアップグレードで作られる **`$WINDOWS.~BT`** や **`$WINDOWS.~WS`** フォルダは、数 GB 単位になることもあります。

そんなときに役立つのが、Windows 標準搭載の **「ディスク クリーンアップ」** です。
この記事では、Windows 11 環境での使い方や注意点をわかりやすくまとめます。

<!-- more -->

## ディスク クリーンアップとは？

- Windows 標準のメンテナンスツール
- 一時ファイルや古い Windows インストールファイルを安全に削除できる
- C ドライブの容量不足を解消し、システムを軽快に保つことができる

## 起動方法

1. **Windowsキー + S** で検索バーを開く
2. 「**ディスク クリーンアップ**」と入力して起動
   - または `cleanmgr` と入力して Enter

## 基本操作の流れ

1. （**複数ドライブがある場合のみ**）「ドライブの選択」画面が表示されるので **Cドライブ** を選んで OK
   - Cドライブしかない環境ではこの画面は表示されず、直接クリーンアップ画面に進みます
2. 一覧が表示されたら **「システム ファイルのクリーンアップ」** をクリック
3. 再度（表示されれば） **Cドライブ** を選択
4. 削除したい項目にチェックを入れる
   - 特に容量が大きいのは **「以前の Windows のインストール」**
   - `$WINDOWS.~BT` や `$WINDOWS.~WS` はここに含まれます
5. **OK → ファイルの削除** を選択して実行

## 削除できる主な項目（Windows 11 日本語版）

> ※ 表示される項目は環境・バージョンによって変わります。太字は容量が大きくなりやすい項目です。

- **Windows Update のクリーンアップ**：累積更新の不要ファイル。容量大になりがち。
- **以前の Windows のインストール**：アップグレード前のシステム一式。**$WINDOWS.~BT / $WINDOWS.~WS を含む**。削除するとロールバック不可。
- **一時 Windows インストール ファイル**：セットアップの残骸。**$WINDOWS.~WS 関連**。
- Windows アップグレード ログ ファイル：アップグレード時のログ類。
- 配信の最適化ファイル：更新プログラムの配布キャッシュ。
- デバイス ドライバー パッケージ：古いドライバのバックアップ。
- DirectX シェーダー キャッシュ：再生成可能。
- サムネイル：再生成可能。
- システム エラー メモリ ダンプ ファイル／ミニダンプ：ブルースクリーン時の記録。大容量になる場合あり。
- Windows Defender ウイルス対策：定義更新の一時データ。
- 一時ファイル：アプリやシステムが作成した不要データ。
- リサイクル ビン：削除済みファイル。
- ダウンロード フォルダー：ユーザーのダウンロードファイル（チェックを入れると削除されるので要注意）。
- 言語リソース ファイル：未使用の言語パック。

> `$WINDOWS.~BT` / `$WINDOWS.~WS` は
> **「以前の Windows のインストール」**、**「一時 Windows インストール ファイル」**、**「Windows アップグレード ログ ファイル」** に含まれます。

## 注意点

削除前に知っておきたいポイント：

- アップグレード後 10日以内に削除すると、前の Windows に戻せなくなる
- 手動でフォルダを直接削除するのは非推奨（必ずクリーンアップツール経由で）
- 実行には数分〜十数分かかることがある

## 自動化する方法：ストレージ センサー

Windows 11 では「ストレージ センサー」を使えば、不要ファイルを自動でクリーンアップできます。

### 設定手順

1. **設定 → システム → ストレージ → ストレージ センサー**
2. 「ストレージ センサーを自動的に実行する」をオンにする
3. 実行タイミング（毎日 / 毎週 / 毎月 / 空き容量が少ないとき）を選択
4. 「今すぐクリーンアップ」で手動実行も可能

## まとめ

- ディスク クリーンアップは **不要ファイルを安全に削除する標準ツール**
- `$WINDOWS.~BT` や `$WINDOWS.~WS` は「以前の Windows インストール」として削除できる
- 削除すると「以前のバージョンに戻す」機能は使えなくなる点に注意
- 定期的に「ストレージ センサー」を有効化しておくと自動的に掃除できて便利
