# Windows 11 GodMode 一覧

## 概要

**GodMode（ゴッドモード）** は、Windows の各種設定や管理ツールを一括で表示する隠しフォルダ機能です。

<!-- more -->

フォルダ名を以下のように変更することで有効になります。

``` txt
GodMode.{ED7BA470-8E54-465E-825C-99712043E01C}
```

作成後、このフォルダを開くと、200 以上の設定項目がカテゴリ別に一覧表示されます。

## 主なカテゴリ一覧

| 項目 | 説明 |

| セキュリティとメンテナンス | セキュリティ設定・問題の確認 |
| Windows Defender ファイアウォール | ファイアウォールの状態と設定 |
| バックアップと復元 | システムのバックアップと復元 |
| BitLocker ドライブ暗号化 | ドライブの暗号化設定 |

## まとめ

| 項目 | 内容 |
|------|------|
| 機能名 | GodMode（マスターコントロールパネル） |
| 有効化方法 | フォルダ名を `{ED7BA470-8E54-465E-825C-99712043E01C}` に変更 |
| 利用目的 | Windows の全設定を一括で管理・アクセス |
| 対応OS | Windows 7 ～ 11 |
| 注意点 | システム設定を変更する際は十分注意する |
