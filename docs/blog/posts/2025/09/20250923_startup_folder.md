# Windows 11 でログイン時に自動起動するアプリを追加する方法

スタートアップフォルダにショートカットを置く方法です。

<!-- more -->

## 手順

1. **スタートアップフォルダを開く**
   - `Windowsキー + R` を押して「ファイル名を指定して実行」を開く。
   - `shell:startup` と入力し、**Enter** を押す。
     → ユーザー専用の「スタートアップ」フォルダが開く。

2. **ショートカットを用意する**
   - 自動起動させたいアプリの `.exe` ファイルを探す。
   - 右クリック → **送る → デスクトップ（ショートカットを作成）** を選ぶ。
     （すでにショートカットがある場合はこの操作は不要）

3. **ショートカットを移動する**
   - 作成したショートカットを「スタートアップ」フォルダにドラッグ＆ドロップする。

4. **動作確認**
   - 一度サインアウトまたは再起動する。
   - ログイン後に、対象アプリが自動的に起動すれば成功。

## 補足

- この方法は「ユーザーごとのスタートアップ」に追加する。
- すべてのユーザーで自動起動したい場合は、以下のフォルダにショートカットを置く。
  `C:\ProgramData\Microsoft\Windows\Start Menu\Programs\StartUp`
- 自動起動をやめたいときは、スタートアップフォルダからショートカットを削除するだけでよい。
